Genetic Code Information

Transcription

DNA → RNA: Thymine (T) is replaced with Uracil (U) in RNA. RNA polymerase creates a complementary RNA strand from the DNA template.

Translation

RNA → Protein: Ribosomes read mRNA in codons (3 bases) to assemble amino acids into proteins. Start codon: AUG (Methionine).

Base Pairing

DNA: A-T (2 hydrogen bonds), C-G (3 hydrogen bonds). RNA: A-U (2 hydrogen bonds), C-G (3 hydrogen bonds).

Genetic Code

The genetic code is nearly universal, with 64 possible codons encoding 20 amino acids and 3 stop signals.
