How to use the collaborative whiteboard:

  • Select a tool from the toolbar (pen, eraser, shapes, etc.)
  • Choose a color from the palette
  • Adjust brush size using the slider
  • Draw on the canvas by clicking and dragging
  • Open this page in another browser tab to see real-time collaboration
  • Use "Undo" to revert your last action
  • Click "Save Image" to download your drawing

This collaborative whiteboard uses localStorage to simulate real-time updates across tabs. Open multiple tabs to see collaboration in action.
