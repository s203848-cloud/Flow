How to Use

  • Type a formula in the input box and click "Analyze"
  • Click elements in the periodic table to add them to your formula
  • Enter two reactants in the Reaction Prediction section to see what reaction will occur
  • The system uses periodic table positions and reactivity trends to predict reactions
  • Use + and - buttons to adjust element counts
  • Click the X button to remove an element
  • Search for elements by name, symbol, or atomic number
  • Use zoom controls to adjust periodic table size
  • Click on reaction examples to load them into the formula builder
