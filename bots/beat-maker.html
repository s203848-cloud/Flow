How to Use the Drum Machine

1. Click on the grid cells to activate/deactivate drum hits for each step.

2. Adjust the tempo using the BPM slider to speed up or slow down the pattern.

3. Select different drum kits to change the sound of each instrument.

4. Use the pattern buttons to save and switch between different beat patterns.

5. Click PLAY to start the sequencer and STOP to pause it.

6. Adjust the overall volume using the volume slider.

7. Click EXPORT MP3 to export your beat as an MP3 file (configurable length and quality).
