Ultimate Circuit Simulator Guide

Getting Started:

1. Drag components from the left panel to the simulation area

2. Click connection points (blue dots) to create wires between components

3. Right-click components for more options (delete, change voltage, etc.)

4. Use different modes for different experiences

Modes:

Sandbox: Free building with all components

Tasks: Complete circuit challenges for points

Modeling: Create custom wire paths and add obstacles

Challenge: Race against time to build circuits

Tips:

• Create closed loops for current to flow
• Hover over components to see edit menu
• Adjust component properties in the right panel
• Save your circuits for later use
